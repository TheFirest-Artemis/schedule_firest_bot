# Telegram-бот «Расписание»

Бот берёт расписание из [гугл-таблицы РУЗ](https://docs.google.com/spreadsheets/d/1kgwKRON2tOFtIgcf0OeoHC3WhT6H4s9F4sEtsgYBVbA/)
и присылает его для вашей группы: текстом или картинкой.

## Возможности

- Доступ к боту закрыт паролем — запрашивается заново при каждом `/start`, без него бот
  не отвечает ни на одну команду.
- Группа задаётся при первом запуске и меняется в «⚙️ Настройки» в любой момент.
- «🗓 Получить расписание» — на N дней вперёд (по умолчанию 3, число дней тоже настраивается
  в «⚙️ Настройки»). «🗓 Расписание на неделю» — всегда на 7 дней.
- Воскресенье в расписании не учитывается совсем.
- Кнопка «🖼 Сохранить как изображение» под расписанием — та же информация в виде картинки-карточки
  (с диапазоном дат в шапке и перерывами между парами).
- Каждая пара: **время и аудитория** (жирным) → тип пары (Лекция/Семинар/Практика, и «Онлайн»,
  если трансляция без очного варианта) → **название предмета** (жирным) → преподаватель и,
  если есть, ссылка на трансляцию.
- Учитываются пометки в таблице о том, что пара идёт не каждую неделю: «С DD.MM» (с этой даты),
  список конкретных дат, «со 2 модуля» (ещё не началась) и разовый перенос времени.
- Данные из таблицы обновляются не чаще раза в 5 минут (по запросу любого пользователя).

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

- `BOT_TOKEN` — токен вашего бота от [@BotFather](https://t.me/BotFather).
- `SPREADSHEET_ID` — уже заполнен (ID таблицы из вопроса).
- `GOOGLE_API_KEY` — см. ниже, без него бот не сможет читать таблицу.
- `BOT_PASSWORD` — пароль, который бот будет спрашивать при каждом `/start`.

### Как получить GOOGLE_API_KEY (5 минут, бесплатно)

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и создайте новый проект
   (или выберите существующий).
2. В меню слева: **APIs & Services → Library**, найдите «Google Sheets API» и нажмите **Enable**.
3. **APIs & Services → Credentials → Create Credentials → API key**.
4. Скопируйте ключ в `.env` как `GOOGLE_API_KEY`.
5. (Рекомендуется) Ограничьте ключ: **Restrict key → API restrictions → Google Sheets API**,
   чтобы им нельзя было пользоваться для других сервисов Google.

Таблица открыта на просмотр по ссылке, поэтому ключа достаточно — доступ через сервисный
аккаунт не нужен.

## Запуск

```bash
python bot.py
```

Бот работает через long polling — держите процесс запущенным (или разверните на сервере,
например через `systemd`/`screen`/`tmux`/Docker). Одновременно должен работать только один
запущенный процесс `bot.py` с этим токеном — иначе Telegram будет присылать ошибку `Conflict`.

## Загрузка на GitHub

Секреты (`.env`, `data/settings.json`) в репозиторий не попадают — это настроено в `.gitignore`.

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <ссылка на ваш пустой репозиторий на GitHub>
git push -u origin main
```

## Перенос на другой компьютер

```bash
git clone <ссылка на репозиторий>
cd tg-schedule-bot
python3 -m venv .venv
source .venv/bin/activate    # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env` теми же значениями (`BOT_TOKEN`, `GOOGLE_API_KEY`, `SPREADSHEET_ID`,
`BOT_PASSWORD`) и запустите `python bot.py`. Файл `data/settings.json` (группы и настройки
пользователей) на новой машине создастся заново — если нужно перенести и его, скопируйте
файл вручную (он не хранится в git).

## Как это устроено

- `sheets_client.py` — запрашивает таблицу через Google Sheets API v4 и кэширует сырые данные
  (значения ячеек + объединения) на 5 минут.
- `schedule_parser.py` — находит колонку нужной подгруппы, строит список пар на N дней вперёд
  (пропуская воскресенья), разбирает пометки о датах и переносах.
- `formatting.py` — форматирует пары в текст для Telegram (HTML-разметка).
- `image_render.py` — рисует то же самое в виде PNG-картинки через Pillow.
- `storage.py` — хранит группу и настройки каждого пользователя в `data/settings.json`.
- `auth.py` + `states.py` (`AuthGate`) — пароль хранится в данных FSM конкретного чата и
  сбрасывается при каждом `/start`, поэтому его нужно вводить заново в каждой новой сессии.

## Особенности формата таблицы

- Группа вида `2615-2` — это связка «год набора (26) + номер группы (15)» и «номер подгруппы (2)».
- Если у таблицы позже появится лист «2 модуль» с такой же структурой (группы/подгруппы/дни/время),
  бот подхватит его автоматически — он ищет нужную группу по всем листам таблицы.
